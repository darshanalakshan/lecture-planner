Setup checklist

  1. Repo Settings → Pages → deploy from branch main, folder / (root).
  2. Repo Settings → Secrets and variables → Actions → add: ICS_URL, RESROBOT_KEY, ORIGIN_ID, DEST_ID, SMTP_USER, SMTP_PASS, EMAIL_TO.
  3. Actions tab → enable workflows. It then runs every evening on its own.
